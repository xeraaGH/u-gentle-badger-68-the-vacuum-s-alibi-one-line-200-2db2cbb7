# The Vacuum's Alibi: One Line, 200 Characters

A program that writes the funniest one-line excuse a robot vacuum can give for missing a spot, 200 characters or fewer, to `/output/entry.txt`.

Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## The line

> I missed that spot because the Wi-Fi dropped and my map reverted to 2019, when that corner was still a wall.
